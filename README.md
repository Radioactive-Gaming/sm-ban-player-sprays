# SourceMod: Ban Player Sprays

A fork of [TnTSCS's plugin](https://forums.alliedmods.net/showthread.php?t=195096).

This plugin will give admins the ability to permanently ban a player's ability
to use the in-game spray function. Once banned, a player will not be able to
spray anymore until an admin removes the ban.

## Admin commands

* `sm_banspray`:
  * **Description:** Permanently remove a player's ability to use sprays based
    on a partial or full name match.
  * **Required Admin Flags**: see `sm_bannedsprays_adminflag_ban`.
  * **Parameters:**
    * **Player name:** (*Optional*) Player's display name on the server. If this
      argument is omitted, the admin is prompted with a menu to select a player.
* `sm_unbanspray`:
  * **Description:** Remove a player's spray ban on a partial or full name match.
  * **Required Admin Flags**: see `sm_bannedsprays_adminflag_ban`.
  * **Parameters:**
    * **Player name:** (*Optional*) Player's display name on the server. If this
      argument is ommited, the admin is prompted with a menw to select a player.
* `sm_banspray_steamid`:
  * **Description:** Manually add a player's SteamID64 identifier to the ban list.
  * **Required Admin Flags**: see `sm_bannedsprays_adminflag_ban`.
  * **Parameters:**
    * **Steam ID:** (*Mandatory*) The 17-digit SteamID64 player identifier.
    * **Status:** (*Mandatory*) Either "allowed" or "banned".
* `sm_deletespray`:
  * **Description:** Removes a player's spray by either looking at it or providing a player's name.
  * **Required Admin Flags**: see `sm_bannedsprays_adminflag_delete`.
  * **Parameters:**
    * **Player name:** (*Optional*) Player's display name on the server. If this
      argument is ommited, the spray under the admin's crosshair is deleted.

## User chat commands

* `!spray`: Display a pop-up which shows information about a spray, such as to
  name of the player who sprayed it, and how long ago it was sprayed.

## Configuration

The primary configuration file is automatically generated by SourceMod and
located at `tf/cfg/sourcemod/plugin.ban_player_sprays.cfg`.

```
// Admins with this permission flag may ban players' sprays
// -
// Default: "d"
sm_bannedsprays_adminflag_ban "d"

// Admins with this permission flag may delete sprays
// -
// Default: "c"
sm_bannedsprays_adminflag_delete "c"

// Assume clients are banned while waiting for the database to load their status
// -
// Default: "0"
sm_bannedsprays_assume_banned "0"

// Automatically remove a player's spray from the map when their spray is banned
// -
// Default: "1"
sm_bannedsprays_autoremove "1"

// Deleted sprays are moved to this location on the map
// -
// Default: "0.00 0.00 0.00"
sm_bannedsprays_delete_loc "0.00 0.00 0.00"

// Players may not create sprays within this radius of an existing spray
// -
// Default: "0"
// Minimum: "0.000000"
sm_bannedsprays_occlusion_radius "0"

// The distance to include sprays during a raycast
// -
// Default: "25"
// Minimum: "0.000000"
// Maximum: "250.000000"
sm_bannedsprays_tracing_dist "25"
```

## Installation

Follow the standard SourceMod process for installation by adding the compiled
plugin `ban_player_sprays.smx` to `tf/addons/sourcemod/plugins/` and reloading
all plugins or restarting the server.
